# Primary background references

1. Dr. Vinayak and Drishya. Who Said "Stop"? A GMM-UBM Speaker
   Verification Competition. Kaggle, 2026.
   https://www.kaggle.com/competitions/who-said-stop-a-gmm-ubm-speaker-verification-competition
2. Pete Warden. Speech Commands: A Dataset for Limited-Vocabulary
   Speech Recognition. 2018. arXiv:1804.03209.
   https://arxiv.org/abs/1804.03209
3. Douglas A. Reynolds, Thomas F. Quatieri and Robert B. Dunn.
   Speaker Verification Using Adapted Gaussian Mixture Models.
   Digital Signal Processing, 2000.
4. MathWorks. Speaker Verification Using Gaussian Mixture Model.
   https://www.mathworks.com/help/audio/ug/speaker-verification-using-gaussian-mixture-model.html
   Discussed as a comparator, not copied: its MFCCs are magnitude-based
   and do not satisfy this competition's feature rule.
5. Sarkar and Tan. Text Dependent Speaker Verification Using Un-supervised
   HMM-UBM and Temporal GMM-UBM. Interspeech 2016.
   The repo includes a separate original torch HMM implementation,
   not a claim to exactly reproduce that paper's corpus or results.

Any directly adapted external code or model must be cited and licensed.
